One line a gamer texts the boss to skip work on GTA 6 launch week.

`main.ts` writes the excuse (17 words, one line) to `/output/entry.txt` and
prints it to stdout. Run with Node 22:

```sh
node main.ts
```

Entry text:

> Sorry, I have to wait in for the fridge delivery, they said between 7am and whenever, apparently

The joke is the delivery window itself: a real, specific, boring detail a
tired manager has heard from every courier, and it quietly traps the sender
at home all day. No dead grandmother, no flat tyre, no sudden fever.
